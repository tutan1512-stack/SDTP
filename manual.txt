Инструкция по заполнению базы данных СДИС

СДИС предназначена для ведения базы данных динамических испытаний свай. Из-за наличия внешних ключей записи необходимо добавлять в определенном порядке.

Порядок заполнения
1. Справочники
Сначала заполните категории производителей, категории транспорта, типы свай, молоты, производителей, транспорт, объекты строительства, сотрудников.
2. Испытуемые сваи
Для каждой сваи укажите номер, тип сваи, производителя и дату изготовления.
3. Динамические испытания
Создайте испытание: подрядчик, заказчик, объект, ответственный, даты, копер, молот.
4. Связь испытаний и свай
После создания испытания привяжите к нему одну или несколько испытуемых свай через таблицу TestedPileInTest.
5. Журнал забивки
Добавляйте этапы забивки. Каждый этап относится к конкретной связке 'испытание–свая'. Номер этапа увеличивается автоматически.
6. Журнал добивки
Добавляется аналогично журналу забивки, но после выдержки сваи.
7. Абсолютные отметки
Заполняются после завершения испытаний для каждой сваи.

Связи между сущностями
• Тип сваи → Испытуемые сваи (1:M)
• Производитель → Испытуемые сваи (1:M)
• Объект → Динамические испытания (1:M)
• Сотрудник → Динамические испытания (1:M)
• Транспорт → Динамические испытания (1:M)
• Молот → Динамические испытания (1:M)
• Динамические испытания ↔ Испытуемые сваи (M:N через TestedPileInTest)
• TestedPileInTest → Журнал забивки (1:M)
• TestedPileInTest → Журнал добивки (1:M)
• Испытуемая свая → Абсолютные отметки (1:M)
• Динамические испытания → Абсолютные отметки (1:M)

Какие данные вводятся
Тип сваи: марка, размеры, армирование, ГОСТ.
Испытуемая свая: номер, тип, производитель, дата изготовления.
Динамическое испытание: подрядчик, заказчик, объект, ответственный, даты, копер, молот.
Журнал забивки: глубина, число ударов, высота подъема молота, средний отказ, примечание.
Журнал добивки: дата, время отдыха, глубина, число ударов, средний отказ.
Абсолютные отметки: отметка головы сваи, конца сваи, поверхности грунта, глубина.

Рекомендуемый порядок работы пользователя
1. Заполнить все справочники.
2. Добавить испытуемые сваи.
3. Создать динамическое испытание.
4. Привязать сваи к испытанию.
5. Внести журнал забивки.
6. Внести журнал добивки.
7. Заполнить абсолютные отметки.
8. Проверить данные через меню просмотра.


Типичные ошибки пользователя
•	Нельзя создавать динамическое испытание, если в базе отсутствуют объект строительства, сотрудник, копер или молот.
•	Нельзя добавить испытуемую сваю, если предварительно не создан тип сваи и производитель.
•	Нельзя добавлять журнал забивки или добивки, пока не создана связь между испытанием и испытуемой сваей (таблица TestedPileInTest).
•	При добавлении нескольких свай к одному испытанию сначала создается испытание, затем каждая связь «испытание–свая».
•	Удаление записи, на которую ссылаются другие таблицы, может вызвать ошибку ограничения внешнего ключа. Сначала необходимо удалить зависимые записи.
•	Перед заполнением рабочих журналов рекомендуется проверить корректность всех справочников.
