# СДИС — Система учета и расчета динамических испытаний свай

## 📋 Описание проекта

**СДИС** (Система динамических испытаний свай) — это консольное приложение на языке Python, предназначенное для автоматизации учета, хранения данных и проведения инженерных расчетов при испытаниях свай динамической нагрузкой на строительных объектах.

Приложение позволяет централизованно вести справочники техники, свай и объектов, регистрировать журналы забивки и добивки свай, учитывать физико-механические свойства грунтов и выполнять расчет несущей способности свай ($F_u$).

### Основные возможности:
* **Управление справочниками и объектами:**
  * **Сваи:** типы и марки свай (ГОСТ, серия, геометрия, масса, армирование), журнал испытуемых свай.
  * **Оборудование:** параметры дизель-молотов (масса ударной части, паспортная/расчетная энергия, масса наголовника) и автопарка (копры, крановая техника, логистика).
  * **Объекты и участники:** строительные объекты, заказчики, производители материалов, контрагенты.
  * **Персонал:** учет сотрудников, ответственных за проведение испытаний.
  * **Грунты:** физико-механические свойства почвенных слоев (ИГЭ, сцепление, угол внутреннего трения, плотность, модуль деформации).
* **Ведение журналов испытаний:**
  * Регистрация динамических испытаний с привязкой к объектам, технике и персоналу.
  * Журнал забивки свай (контроль погружения, количества ударов, высоты подъема молота, среднего отказа).
  * Журнал добивки свай (учет времени «отдыха» грунта, замер отказов).
  * Журнал абсолютных отметок (голова сваи, острие, поверхность грунта).
* **Инженерные расчеты:**
  * Автоматический расчет несущей способности сваи по результатам добивки с учетом массы оборудования, отказов и геометрических параметров.
* **Архитектура и хранение:**
  * Построено на ORM **SQLAlchemy 2.0** (база данных SQLite).
  * При работе в скомпилированном виде база данных создается автоматический в изолированном пользовательском каталоге (`AppData/Roaming/MyPythonApp/database.db`), при разработке — локально в папке проекта.

## 🚀 Инструкция по сборке готовой программы

### Способ 1. Автоматическая сборка через `build.bat` (Рекомендуется)

В корне проекта находится готовый пакетный файл для автоматической сборки `build.bat`.

1. Откройте командную строку (`cmd.exe`) или PowerShell в папке проекта.
2. Запустите скрипт сборки:
   ```cmd
   build.bat
   ```
3. Скрипт выполнит следующие операции:
   * Проверит наличие виртуального окружения `.venv` и создаст его при отсутствии.
   * Установит все необходимые зависимости из файла `requirements.txt`.
   * Запустит компиляцию приложения с помощью **PyInstaller** (`pyinstaller --onefile ./menu.py`).
4. После завершения сборки готовый исполняемый файл появится в папке `dist`:
   ```text
   dist/menu.exe
   ```

---

### Способ 2. Ручная сборка через командную строку

Если требуется выполнить сборку пошагово вручную:

1. **Создайте виртуальное окружение Python:**
   ```bash
   python -m venv .venv
   ```

2. **Активируйте виртуальное окружение:**
   * Командная строка Windows (`cmd`):
     ```cmd
     .\.venv\Scriptsctivate.bat
     ```
   * PowerShell:
     ```powershell
     .\.venv\Scripts\Activate.ps1
     ```

3. **Установите требуемые библиотеки:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите компиляцию в единственный `.exe` файл:**
   ```bash
   pyinstaller --onefile ./menu.py
   ```

5. **Результат:**
   Готовый исполняемый файл `menu.exe` будет сохранен в рабочей директории `./dist/`.
