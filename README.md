# СДИС — Система учета и расчета динамических испытаний свай

## Описание проекта

**СДИС** (Система динамических испытаний свай) — это консольное приложение на языке Python, предназначенное для автоматизации учета, хранения данных и проведения инженерных расчетов при испытаниях свай динамической нагрузкой на строительных объектах.

Приложение позволяет централизованно вести справочники техники, свай и объектов, регистрировать журналы забивки и добивки свай, учитывать физико-механические свойства грунтов и выполнять расчет несущей способности свай ($F_u$).

### Основные возможности:
* **Управление справочниками и объектами:**
  * **Сваи:** типы и марки свай (ГОСТ, серия, геометрия, масса, армирование), журнал испытуемых свай.
  * **Оборудование:** параметры дизель-молотов (масса ударной части, паспортная/расчетная энергия, масса наголовника) и автопарка (копры, крановая техника, логистика).
  * **Объекты и участники:** строительные объекты, заказчики, производители материалов, контрагенты.
  * **Персонал:** учет сотрудников, ответственных за проведение испытаний.
  * **Грунты:** физико-механические свойства почвенных слоев (ИГЭ, сцепление, угол внутреннего трения, плотность, модуль деформации).
* **Ведение журналов испытаний:**
  * Регистрация динамических испытаний с привязкой к объектам, технике и персоналу.
  * Журнал забивки свай (контроль погружения, количества ударов, высоты подъема молота, среднего отказа).
  * Журнал добивки свай (учет времени «отдыха» грунта, замер отказов).
  * Журнал абсолютных отметок (голова сваи, острие, поверхность грунта).
* **Инженерные расчеты:**
  * Автоматический расчет несущей способности сваи по результатам добивки с учетом массы оборудования, отказов и геометрических параметров.
* **Архитектура и хранение:**
  * Построено на ORM **SQLAlchemy 2.0** (база данных SQLite).
  * При работе в скомпилированном виде база данных создается автоматический в изолированном пользовательском каталоге (`AppData/Roaming/MyPythonApp/database.db`), при разработке — локально в папке проекта.

### Инструкция по заполнению базы данных СДИС
#### Порядок заполнения
1. Справочники
Сначала заполните категории производителей, категории транспорта, типы свай, молоты, производителей, транспорт, объекты строительства, сотрудников.
2. Испытуемые сваи 
Для каждой сваи укажите номер, тип сваи, производителя и дату изготовления.
3. Динамические испытания 
Создайте испытание: подрядчик, заказчик, объект, ответственный, даты, копер, молот.
4. Связь испытаний и свай 
После создания испытания привяжите к нему одну или несколько испытуемых свай через таблицу TestedPileInTest.
5. Журнал забивки
Добавляйте этапы забивки. Каждый этап относится к конкретной связке 'испытание–свая'. Номер этапа увеличивается автоматически.
6. Журнал добивки
Добавляется аналогично журналу забивки, но после выдержки сваи.
7. Абсолютные отметки
Заполняются после завершения испытаний для каждой сваи.

#### Связи между сущностями 
    Тип сваи → Испытуемые сваи (1:M)
    Производитель → Испытуемые сваи (1:M)
    Объект → Динамические испытания (1:M)
    Сотрудник → Динамические испытания (1:M)
    Транспорт → Динамические испытания (1:M)
    Молот → Динамические испытания (1:M)
    Динамические испытания ↔ Испытуемые сваи (M:N через TestedPileInTest)
    TestedPileInTest → Журнал забивки (1:M)
    TestedPileInTest → Журнал добивки (1:M)
    Испытуемая свая → Абсолютные отметки (1:M)
    Динамические испытания → Абсолютные отметки (1:M)

#### Какие данные вводятся 
* Тип сваи: марка, размеры, армирование, ГОСТ
* Испытуемая свая: номер, тип, производитель, дата изготовления
* Динамическое испытание: подрядчик, заказчик, объект, ответственный, даты, копер, молот
* Журнал забивки: глубина, число ударов, высота подъема молота, средний отказ, примечание
* Журнал добивки: дата, время отдыха, глубина, число ударов, средний отказ
* Абсолютные отметки: отметка головы сваи, конца сваи, поверхности грунта, глубина

#### Рекомендуемый порядок работы пользователя
1. Заполнить все справочники.
2. Добавить испытуемые сваи.
3. Создать динамическое испытание.
4. Привязать сваи к испытанию.
5. Внести журнал забивки.
6. Внести журнал добивки.
7. Заполнить абсолютные отметки.
8. Проверить данные через меню просмотра.


#### Типичные ошибки пользователя
* *Нельзя создавать динамическое испытание, если в базе отсутствуют объект строительства, сотрудник, копер или молот.*
* *Нельзя добавить испытуемую сваю, если предварительно не создан тип сваи и производитель.*
* *Нельзя добавлять журнал забивки или добивки, пока не создана связь между испытанием и испытуемой сваей (таблица TestedPileInTest).*
* *При добавлении нескольких свай к одному испытанию сначала создается испытание, затем каждая связь «испытание–свая».*
* *Удаление записи, на которую ссылаются другие таблицы, может вызвать ошибку ограничения внешнего ключа. Сначала необходимо удалить зависимые записи*
* *Перед заполнением рабочих журналов рекомендуется проверить корректность всех справочников*

## Инструкция по сборке готовой программы

### Способ 1. Автоматическая сборка через `build.bat` (Рекомендуется)

В корне проекта находится готовый пакетный файл для автоматической сборки `build.bat`.

1. Откройте командную строку (`cmd.exe`) или PowerShell в папке проекта.
2. Запустите скрипт сборки:
   ```cmd
   build.bat
   ```
3. Скрипт выполнит следующие операции:
   * Проверит наличие виртуального окружения `.venv` и создаст его при отсутствии.
   * Установит все необходимые зависимости из файла `requirements.txt`.
   * Запустит компиляцию приложения с помощью **PyInstaller** (`pyinstaller --onefile ./menu.py`).
4. После завершения сборки готовый исполняемый файл появится в папке `dist`:
   ```text
   dist/menu.exe
   ```

---

### Способ 2. Ручная сборка через командную строку

Если требуется выполнить сборку пошагово вручную:

1. **Создайте виртуальное окружение Python:**
   ```bash
   python -m venv .venv
   ```

2. **Активируйте виртуальное окружение:**
   * Командная строка Windows (`cmd`):
     ```cmd
     .\.venv\Scriptsctivate.bat
     ```
   * PowerShell:
     ```powershell
     .\.venv\Scripts\Activate.ps1
     ```

3. **Установите требуемые библиотеки:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите компиляцию в единственный `.exe` файл:**
   ```bash
   pyinstaller --onefile ./menu.py
   ```

5. **Результат:**
   Готовый исполняемый файл `menu.exe` будет сохранен в рабочей директории `./dist/`.
